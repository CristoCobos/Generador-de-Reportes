# Generador de Reportes

Proyecto desarrollado en **R** para automatizar la generación de reportes estadísticos en **PDF** a partir de bases de datos institucionales, utilizando **Sweave** y **LaTeX**.

## Estado del proyecto

> **⚠️ En desarrollo (Work in Progress).**

Este proyecto aún se encuentra en construcción. El objetivo es replicar y mejorar un sistema existente para automatizar la creación de informes por programa educativo, incorporando procesamiento de datos, generación de tablas, gráficas y reportes en PDF.

## Tecnologías

* R
* Sweave
* LaTeX
* dplyr
* tidyr
* ggplot2
* readxl
* xtable

## Objetivo

Automatizar el flujo completo de generación de reportes:

* Procesamiento de bases de datos.
* Generación de tablas y gráficas.
* Integración de resultados en plantillas Sweave.
* Exportación automática de informes en PDF.

## Nota

El repositorio aún no representa una versión final ni estable. La estructura, funcionalidades y documentación continuarán actualizándose conforme avance el desarrollo.
